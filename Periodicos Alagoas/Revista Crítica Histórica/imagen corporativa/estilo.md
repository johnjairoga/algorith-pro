# Revista Crítica Histórica — Guía de Estilo

## Identidad Visual

The design system uses a warm, earthy palette with rust-red accents against soft beige, creating a sophisticated vintage editorial look. The typography is bold and impactful, with generous whitespace and asymmetrical framing that emphasizes historical/archival content.

---

## Three Colours. Fixed Roles.

**Rule: 3 colours, fixed roles, every post.**

| Role | Colour | Hex | Usage |
|------|--------|-----|-------|
| **PRIMARY** | Rust-Red / Terracotta | `#A64D3F` | Defines identity and emphasis. Headlines, underlines, borders, decorative lines, frames, tag backgrounds. |
| **BACKGROUND** | Beige / Cream / Off-white | `#E8DDD0` | Neutral canvas. Page backgrounds, card bases. Maintains warm, vintage editorial feel. |
| **ACCENT** | Dark Brown / Maroon | `#3C2419` | Emphasis, used sparingly. Primary text, fine details, high contrast. Must pass squint test. |

**Application:**
- Every post uses all 3 colours in these fixed roles
- Primary rust-red (#A64D3F) drives visual hierarchy
- Consistency across all articles ensures cohesive aesthetic
